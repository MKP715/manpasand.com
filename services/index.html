§ 03  Limits

What we don’t do

Some work needs a license we don’t hold, so we don’t offer it.

Security cameras and alarms

We don’t install security cameras or alarm systems. Texas requires a DPS Private Security license for that work, and we don’t hold one. Hire a licensed company — you can check any installer at tops.portal.texas.gov.

Electrical work

We don’t wire anything into your electrical panel or run power circuits. That’s a job for an electrician. Office network cabling for computers, phones and Wi‑Fi is work we do.
